# منصة التقييم والتصويت التفاعلي

نسخة عملية بخادم Node.js (بدون حزم خارجية)، وواجهات عربية للمتدرب والمدرب والنتائج.

## التشغيل

1. ثبّت Node.js إصدار 18 أو أحدث.
2. شغّل الخادم من داخل مجلد المشروع:

   **macOS / Linux:** `ADMIN_PASSWORD='ضع-كلمة-مرور-قوية' node server.js`

   **Windows PowerShell:** `$env:ADMIN_PASSWORD='ضع-كلمة-مرور-قوية'; node server.js`

3. افتح `http://localhost:3000`.
4. في «لوحة المدرب»، أدخل كلمة المرور، حدد الأسماء وطريقة التصويت، ثم أنشئ رموز المتدربين ونزّلها CSV.
5. وزّع لكل متدرب رمزًا خاصًا، وافتح التصويت للمجموعة الأولى ثم أغلقه وكرر لبقية المجموعات.

## مشاركة التصويت على الجوالات

لا يكفي فتح ملف HTML وحده. يحتاج المتدربون للوصول إلى **الخادم نفسه** عبر رابط متاح لأجهزتهم. داخل الشبكة المحلية، استخدم عنوان IP لجهاز المدرب مثل `http://192.168.1.10:3000` إذا سمحت الشبكة بالاتصال. للاستخدام من خارج الشبكة، انشر التطبيق على استضافة تدعم Node.js وتخزينًا دائمًا وHTTPS؛ الرابط العام هو رابط التصويت ويمكن توليد QR له داخل لوحة المدرب.

## خصائص التطبيق

- تصويت منفصل لكل مجموعة من 1 إلى 10، وصوت واحد لكل رمز لكل مجموعة.
- الوضع المجهول أو التصويت بالاسم (يُضبط قبل أول تصويت).
- لوحة تحكم المدرب، نتائج حية عبر Server-Sent Events، مجموع الأصوات ومتوسطها، ترتيب الفائز.
- ملفات التصويت تخزَّن في `data.json` على خادم واحد، لذلك لا تستخدم استضافة تحذف الملفات أو تنشئ نسخًا متعددة دون قاعدة بيانات.
- لا تُعرض أسماء المتدربين في نتائج الجمهور؛ يستطيع المدرب رؤية الأصوات المسجلة في واجهة API المصرح بها (لم نضف تصديرها بعد).

## ملاحظات أمنية وتشغيلية

- **غيّر كلمة المرور** قبل نشر الموقع؛ القيمة الافتراضية مخصصة للتجربة فقط.
- لا تشارك رموز المتدربين علنًا؛ هي وسيلة الحد من تكرار التصويت وليست تحققًا قويًا للهوية.
- رمز المسؤول يبقى في ذاكرة الخادم ويخزَّن في ملف البيانات، لذلك احمِ ملف البيانات ولا تنشره ضمن مجلد ويب عام.
- طريقة الانتخاب تعتمد على المتوسط، ويُعلن الفائز فقط بعد اكتمال التصويت على جميع المجموعات ووجود أصوات لكل منها.
- في حال تعطل الخادم، أعد تشغيله؛ البيانات محفوظة في `data.json` على القرص ما دام التخزين دائمًا.
